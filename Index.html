3. Harga Tidak Dapat di Nego.

4. Revisi Hanya Diperbolehkan Sebanyak 5x.

6. Untuk Livestreaming Bisa Request Akun di beberapa platform Customer (Jika Tidak Request akan dialihkan ke channel khusus Sabada Organizer).

7. Ada Sistem Garansi (Jika Ada kesalahan Teknis, Human Error, atau dari Pihak Admin Uang Akan Dikembalikan 100%).

9. Lama Pengerjaan design Serta overlay 1-7 hari tergantung tingkat kesulitan, kondisi, Dan antrian.

10. Antrian Bisa dipercepat tapi harus ada biaya tambahan.

11. Setiap setelah order disepakati dari pihak pembeli, pembeli wajib memberikan bukti pembayaran terlebih dahulu sebagai gantinya admin akan memberikan garansi 100% uang kembali jika terjadi kesalahan (khusus event order DLL).
